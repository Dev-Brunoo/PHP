# 🐘 Práticas de PHP - Exercícios Curtos

Este repositório foi criado com o objetivo de consolidar meus estudos diários na linguagem PHP. Aqui eu coloco pequenos desafios e códigos práticos para testar conceitos do mundo real.

## 🎯 Foco dos Estudos Atuais
* **Tratamento de Erros:** Domínio das estruturas `try`, `catch` e `finally`.
* **Arquitetura Defensiva:** Uso do `throw` para validação de regras de negócio (*Fail-Fast*).
* **Lógica Avançada:** Criação de funções resilientes e tratamento de exceções específicas do PHP.

## 🛠️ Tecnologias e Ferramentas
* **Linguagem:** PHP 8+
* **Ambiente de Testes:** Servidor embutido do PHP (`php -S localhost:8000`)
* **Editor:** VS Code
